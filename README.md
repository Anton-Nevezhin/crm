# CRM система (клиенты, сделки, контакты)

Полнофункциональная CRM для управления клиентами, сделками и контактами. Учебный проект, демонстрирующий навыки разработки на Laravel.

## Функционал

- Клиенты — CRUD, поиск, фильтры по дате и сумме сделок, сортировка, пагинация, экспорт в Excel/CSV
- Сделки — CRUD, поиск, фильтры по статусу, дате, сумме, сортировка, пагинация, экспорт в Excel
- Контакты — CRUD, фильтры по типу, дате, клиенту, пагинация, экспорт в Excel
- Аутентификация — регистрация, вход, защита маршрутов
- API — REST API для всех сущностей (JSON)
- Админ-панель — сводная статистика по системе
- Дашборд — приветствие, карточки с данными, быстрые ссылки
- Отчёты — динамика сделок по дням, топ-5 клиентов, воронка продаж, отчёт по месяцам
- Тесты — 29 тестов PHPUnit (покрытие CRUD и API)
- Стилизация — единый дизайн, адаптив

## Технологии

- Laravel 10
- PHP 8.1
- MySQL
- Laravel Breeze (аутентификация)
- PHPUnit (тесты)
- PhpSpreadsheet (Excel)
- Telegram Bot API
- Git / GitHub

## Установка

git clone https://github.com/Anton-Nevezhin/crm.git
cd crm
composer install
cp .env.example .env
php artisan key:generate

Настройте подключение к базе данных в .env, затем выполните:

php artisan migrate --seed
php artisan serve

## Доступ в систему

После регистрации первого пользователя он получает доступ ко всем разделам.

Для быстрого тестирования зарегистрируйтесь через форму регистрации.

## API

GET    /api/clients      Список клиентов
POST   /api/clients      Создать клиента
GET    /api/clients/{id} Просмотр клиента
PUT    /api/clients/{id} Обновить клиента
DELETE /api/clients/{id} Удалить клиента

Аналогично для /api/deals и /api/contacts.
